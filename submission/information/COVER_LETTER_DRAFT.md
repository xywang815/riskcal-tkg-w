# Cover Letter Draft for MDPI Information

Dear Editors,

We are pleased to submit our manuscript, tentatively titled "Prequential Answer-Set Calibration for Temporal Knowledge Graph Forecasting: An ICEWS14 Diagnostic Study", for consideration as an Article in `Information`.

The manuscript studies a practical reliability question in temporal knowledge graph forecasting: when candidate answer sets are calibrated from historical scores, static calibration can become stale as the event stream evolves. We evaluate this issue under a strict prequential protocol on ICEWS14, separating ranking quality, observed-label coverage, query-level answer-set coverage, and candidate-set size.

The contribution is diagnostic and empirical. We do not claim a new distribution-free coverage theorem under temporal drift, nor do we claim state-of-the-art temporal KG ranking performance. Instead, the paper provides a bounded reliability-utility evaluation showing that rolling prequential calibration can restore near-target observed-label coverage while incurring substantial answer-set size costs. We further report rank-shortlist and validation-selected RAPS rolling diagnostics, relation-side worst-group coverage, delayed-feedback sensitivity, and rolling-window ablations.

To support review and reproducibility, we provide source code, configurations, fixed seeds, paper-facing result tables, and figures in a public repository. The repository URL is:
