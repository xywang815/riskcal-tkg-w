# Official MDPI Information Links

Use these links when preparing the MDPI `Information` submission.

- Journal homepage: https://www.mdpi.com/journal/Information
- Indexing page: https://www.mdpi.com/journal/information/indexing
- Journal history: https://www.mdpi.com/journal/information/history
- MDPI LaTeX templates: https://www.mdpi.com/authors/latex
- MDPI author guidelines: https://www.mdpi.com/authors
- MDPI layout guide: https://www.mdpi.com/authors/layout
- MDPI APC information: https://www.mdpi.com/apc
- MDPI Ei Compendex journal list: https://www.mdpi.com/about/journals/compendex

Current official information checked on 2026-08-19:

- `Information` is indexed in Scopus, ESCI, Engineering Village / Ei Compendex, dblp, Inspec, and other services.
- MDPI lists `Information` APC as CHF 1800 on the APC information page.
- MDPI LaTeX submission should use the current MDPI template files from the official LaTeX template page.
