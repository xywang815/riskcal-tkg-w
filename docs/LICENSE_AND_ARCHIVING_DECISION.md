# License and Archiving Decision

Before submitting to MDPI `Information`, choose a license and create a permanent archival record.

## Recommended Code License

Selected license: MIT License.

Repository URL: https://github.com/xywang815/riskcal-tkg-w

Why:

- simple and widely accepted for academic code;
- permits reuse with attribution;
- low friction for reviewers and future readers;
- compatible with most research workflows.

Alternative:

- Apache-2.0 if you want an explicit patent grant.
- GPL-3.0 only if you want derivative code to remain open source, but it can discourage reuse.

Do not publish without a license. Without a license, others may be legally unable to reuse the code even if the repository is public.

## Recommended Archive Workflow

1. Create the public GitHub repository.
2. Push the cleaned project.
3. Add a `LICENSE` file.
4. Create a GitHub release, for example `v1.0-information-submission`.
5. Link GitHub with Zenodo.
6. Archive the release on Zenodo.
7. Add the Zenodo DOI to the manuscript and cover letter.

## Suggested Repository Citation

Once the DOI exists, cite it in the manuscript as a software/data availability resource. Do not cite local paths, temporary archives, or server run IDs.
